Macro global · EODHD
Capacidades
Cuatro skills. Un agente.

Jane aplica automáticamente el análisis correcto según tu pregunta. Sin código. Sin formularios. Solo lenguaje natural.

🌍
Régimen de mercado
Clasifica el estado actual del mercado (alcista, bajista, lateral, crisis) usando MA200, VIX y curva de rendimientos.
🔬
Microestructura
Lee el mercado como Jane Street: spread bid-ask, ADV, señal de flujo y slippage estimado.
📈
Volatilidad
Compara volatilidad implícita vs histórica. Detecta si las opciones están caras o baratas. Skew y estructura temporal.
🔗
Stat-Arb
Identifica pares cointegrados, calcula el Z-score actual y estima el half-life de reversión usando OLS + Ornstein-Uhlenbeck.
Glosario
Terminología que Jane usa. Explicada sin filtros.

Cada concepto incluye definición, cómo se mide y un ejemplo real.

microestructura
Spread bid-ask
La diferencia entre lo que el mercado paga y lo que cobra. Un spread de 0.5% significa que pierdes 1% solo entrando y saliendo.
volatilidad
IV vs HV
Volatilidad Implícita (lo que el mercado espera) vs Volatilidad Histórica (lo real). Cuando IV > HV, las opciones están caras.
stat-arb
Z-score
Cuántas desviaciones estándar está una divergencia de su media. Z > +2.0 = señal de entrada. Z = 0 = objetivo de salida.
régimen
VIX
El "índice del miedo". Mide la volatilidad esperada 30 días. VIX < 15 = calma. VIX > 30 = estrés. VIX > 40 = pánico.
régimen
Curva de rendimientos
Diferencia entre tasa 10Y y 2Y. Positiva = economía sana. Invertida = alerta de recesión. Precedió todas las recesiones de EEUU en 50 años.

Cómo usar Jane
Tres formas. Elige la tuya.
1
Sin instalar nada — Claude.ai
Abre claude.ai (cuenta gratuita), crea un Project con las instrucciones del agente y empieza en lenguaje natural. Sin código, sin API keys.
2
Análisis en vivo — Web
Abre openjane.onrender.com/analyze, ingresa tus API keys de Massive y EODHD (ambas gratuitas) y obtén análisis en tiempo real desde el navegador.
3
Deploy propio — Docker
Clona el repo, usa el Dockerfile incluido y despliega en cualquier plataforma. Imagen Python 3.12, FastAPI + uvicorn, sin dependencias externas.
