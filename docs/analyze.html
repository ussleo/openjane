⚠ Plataforma de pruebas y aprendizaje. Ninguna API key ni dato ingresado se almacena en ningún servidor. Todo vive exclusivamente en tu sesión de navegador y desaparece al cerrar la pestaña o pulsar F5. Si en algún momento sientes que tus keys están en riesgo, usa el botón de pánico.

⚠ Limpiar sesión completa

Esto eliminará todas tus API keys del formulario, borrará todos los resultados visibles y limpiará el almacenamiento de sesión.

Es equivalente a abrir la página en modo incógnito desde cero.

No podemos revocar tus keys — eso debes hacerlo tú en el panel de Massive.com y EODHD si sospechas de una filtración real.

[ OpenJane ] — Antes de empezar
1
Obtén tus API keys gratuitas. Necesitas dos: Massive.com (datos de precio y volumen) y EODHD (medias móviles, yield curve). Ambas son gratis, sin tarjeta de crédito. Guía paso a paso →
2
Ingresa las keys en el formulario de abajo. Se envían directamente al servidor por HTTPS y nunca se almacenan. Cada análisis requiere ambas keys.
3
Elige un análisis y corre. Régimen de mercado (SPY global), Microestructura (cualquier ticker) o Stat-Arb (par de tickers). El primer resultado puede tardar ~30s si el servidor estaba inactivo.
⚠ Sin API keys el sistema no funciona. Los datos de precio y macroeconómicos provienen de APIs externas — OpenJane no almacena ni cachea datos de mercado. Tiempo estimado para obtener tus keys: 3 minutos.
